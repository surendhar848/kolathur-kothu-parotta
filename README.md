# Kolathur Kothu Parotta

A modern and responsive restaurant website built for **Kolathur Kothu Parotta**.

The website showcases the restaurant's food offerings, menu, services, and contact information through a clean and engaging user interface.

## Live Website

https://kolathur-kothu-react-rupees.vercel.app/

## Features

- Responsive restaurant website
- Modern and user-friendly UI
- Food and menu showcase
- Restaurant information
- Contact section
- Mobile-friendly design
- Fast and lightweight frontend
- Deployed on Vercel

## Tech Stack

- React
- JavaScript
- HTML5
- CSS3
- Vercel
